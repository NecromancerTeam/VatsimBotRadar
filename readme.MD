VATSIM Airport Info Bot



​Telegram-бот на Python для оперативного получения информации об аэропортах и зоне ответственности (FIR) в сети VATSIM.

​Бот парсит данные напрямую через VATSIM Data API и VATSIM METAR Service, обрабатывает активные позиции диспетчеров, выдает рабочие полосы из ATIS, парсит погоду с расшифровкой и отправляет файлы чартов/схем(проблема,не раюотает)

​Функционал
​Погода METAR: Загрузка актуального METAR с автоматическим парсингом и расшифровкой ветра, облачности и явлений погоды (поддержка JSON-словарей локализации).
​Статус ОВД (ATC): Определение активных позиций контроля в аэропорту (Del, Gnd, Twr, App/Dep) и поиск верхнего контроля (CTR / FIR), если позиция подхода оффлайн.
​Рабочие полосы: Извлечение используемых полос (ARR/DEP RWY) из текста актуального ATIS.
​Чарты аэропортов: Автоматический поиск и отправка файлов схем/чартов из локальной директории при наличии.
​Локализация: Вынос словарей перевода METAR в отдельный JSON-файл для удобного пополнения без правки кода.

​Стек технологий:
​Python 3.10+
​Aiogram 3.x — асинхронный фреймворк для Telegram Bot API
​aiohttp — асинхронные HTTP-запросы
​python-dotenv — управление переменными окружения


Команды:
​/start — Запуск бота, вывод приветственного сообщения и базовых ссылок.
​/help — Инструкция по использованию и примеры запросов.
​/info — Информация о проекте и контакты разработчика.
​[ICAO] — Отправка 4-буквенного кода аэропорта для получения сводки.

Устоновка:
1)Клонируй репозиторий: https://github.com/NecromancerTeam/VatsimBotRadar.git
2)Создай вирт окружения venv:
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate  # Windows
3)Устонови зависимости бота:
pip install -r requirements.txt
4)Создай файл .env в корневой папке бота и укажи там: BOT_TOKEN=(ваш токен) 
пример: BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
5) Запуск бота : python main.py
